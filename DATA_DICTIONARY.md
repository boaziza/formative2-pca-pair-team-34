# EICV5 PCA subset — data dictionary

Source: NISR, Rwanda Integrated Household Living Conditions Survey (EICV5) 2016–2017, file `EICV5_Poverty_file.dta`
https://microdata.statistics.gov.rw/index.php/catalog/82

One row per household (14,580 households). Monetary values in Rwandan francs per year.

| Column | Original variable | Description | Type |
|---|---|---|---|
| province | province | Province | text |
| urban_rural | ur | Urban / Rural | text |
| hh_size | member | Household size | numeric |
| consumption_per_ae | cons1_ae | Aggregate consumption per adult equivalent | numeric |
| food_share | foodshare1 | Share of food in total household consumption | numeric |
| food_expenditure | exp15_2 | Food expenditures | numeric |
| own_food_production | exp16_2 | Own food consumption (home-grown) | numeric |
| annual_nonfood_exp | exp12 | Annual non-food expenditures | numeric |
| education_exp | exp1 | Education expenses | numeric |
| water_exp | exp7 | Water expenses | numeric |
| electricity_exp | exp8 | Electricity expenses | numeric |
| durable_goods_value | exp17 | Use value of durable goods (6 missing in original) | numeric |
| transfers_received | exp18 | Value of in-kind transfers received (5 missing in original) | numeric |
